## About Me

我正在训练自己成为一名 <strong>职业人工智能选手（Professional AI Player）</strong>。

我希望构建的不是单一技术栈，而是一套可以不断迁移的能力：面对一个陌生领域，快速理解问题，借助人工智能学习必要的领域知识，构建可运行的解决方案，并通过真实项目、研究与 Hackathon 持续验证和迭代。

> **快速理解问题 → AI 辅助跨学科学习 → 构建解决方案 → 真实验证 → 复盘迭代**

我把不同学科视为训练场，把项目视为训练单元，把 Hackathon 视为竞技场。

## Hackathon Arena

Hackathon 对我来说不是一次性的比赛，而是一种高强度训练机制：

**Understand fast → Build fast → Validate fast → Learn fast.**

我希望通过持续参加 Hackathon、开发竞赛与开放式挑战，训练以下能力：

- 在不完整信息下快速定义问题
- 使用 AI 快速学习陌生领域
- 将想法压缩成最小可验证产品
- 在时间限制下完成真实工程交付
- 与不同专业背景的人协作
- 赛后复盘，并把经验沉淀为下一次的工具与方法
